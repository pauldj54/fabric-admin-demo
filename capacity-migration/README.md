# Capacity migration discovery notebooks

The discovery notebook's semantic model definition contains placeholders
`YOUR_SQL_ENDPOINT` and `YOUR_DATABASE_ID` in the `DatabaseQuery` expression.
Before running it, replace them with the SQL analytics endpoint and database
name or ID for your own target Lakehouse. The notebook later updates the
Direct Lake model's Lakehouse connection.

See the [repository user guide](../README.md) for the sizing pilot.
